📊 Simulador e Consultoria Financeira - Antonucci Invest

📖 Descrição do Projeto

Este projeto consiste em uma planilha de simulação de investimentos e consultoria financeira desenvolvida para o desafio. O painel interativo, intitulado Antonucci Invest - Consultoria Financeira Inteligente e Segura, permite que o usuário projete seu futuro financeiro com base em aportes mensais, analisando o crescimento do patrimônio e a geração de renda passiva (dividendos) ao longo do tempo.

Além da projeção de juros compostos, a ferramenta inclui um módulo de diversificação de carteira focado em Fundos de Investimento Imobiliário (FIIs), adaptado para um perfil de investidor moderado, agressivo, conservador.

🎯 Objetivo

O principal objetivo deste projeto é demonstrar de forma visual e prática o poder dos juros compostos no longo prazo e auxiliar na estruturação inicial de uma carteira de investimentos diversificada.

⚙️ Funcionalidades e Estrutura da Planilha

A planilha está dividida em quatro painéis principais:

Configurações Básicas:

Recebe os dados de entrada como o Salário (ex: R$ 2.500,00).

Define o rendimento médio esperado da carteira.

Sugere uma meta ideal de investimento com base em uma porcentagem do salário (ex: 30%).

Investimento Mensal:

Permite simular o valor do aporte mensal (ex: R$ 300,00).

Calcula o patrimônio acumulado e a renda passiva (dividendos) gerada ao final de um período de anos estipulado com base em uma taxa de rendimento mensal.

Cenários de Longo Prazo:

Apresenta uma tabela dinâmica com projeções automáticas para 2, 5, 10, 20 e 30 anos.

Mostra a evolução lado a lado do Patrimônio Acumulado versus os Dividendos Mensais recebidos em cada cenário.

Alocação de Carteira de FIIs (Perfil Moderado):

Distribui o aporte mensal definido (ex: R$ 300,00) em diferentes setores de FIIs seguindo uma estratégia de diversificação:

📄 Papel: 32%

🧱 Tijolo: 35%

🔄 Híbridos: 8%

🏢 FoFs: 5%

🏗️ Desenvolvimento: 10%

🏨 Hotelarias: 10%

Inclui um Gráfico de Pizza para facilitar a visualização da diversificação da carteira.

🛠️ Tecnologias Utilizadas

Microsoft Excel (ou software de planilhas equivalente) para cálculos financeiros, lógica de juros compostos e geração de gráficos.

GitHub para versionamento e entrega do projeto.
